# 💼 Real or Fake Job Detection

A Machine Learning-based web application that detects whether a job posting is **Real** or **Fake** by analyzing the job description using Natural Language Processing (NLP) techniques. The application provides a simple web interface where users can enter job details and receive an instant prediction.

---

## 🚀 Features

- 🔍 Detects Real and Fake Job Postings
- 🤖 Machine Learning-based Prediction
- 📝 Analyze Job Descriptions
- 🌐 User-Friendly Web Interface
- ⚡ Instant Prediction Results
- 📊 NLP-based Text Processing
- 💻 Responsive Frontend

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Aqsachanna/Real-or-Fake-Job-Detection.git
```

### Navigate to the Project Folder

```bash
cd Real-or-Fake-Job-Detection
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000/
```

---

## 🎯 How It Works

1. Enter the job posting details.
2. The text is preprocessed using NLP techniques.
3. The trained machine learning model analyzes the input.
4. The application predicts whether the job is **Real** or **Fake**.
5. The prediction is displayed instantly on the web page.
